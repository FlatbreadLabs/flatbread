Status — NEXT-CALL-UNANNOUNCED.

How to apply —

1. Watch https://astera.org/residency/ for the next cycle.
2. When a cycle opens, submit the form linked from that page. The last cycle asked for a 2-minute project video and eight short answers (each under 1,000 characters).
3. If invited, take a 15 to 25 minute intro call.
4. Then file a detailed proposal with a budget and milestones.
5. Later rounds include more conversations with the Astera team.

Opportunity value — 86. cash/credits/exposure/research = 40/30/6/10.

Confidence — 18 (VERY LOW). No published acceptance rate on the pages opened. The last fall cycle used a multi-stage filter. The project matches the open-public-goods rule and the intelligence focus, but the next window is unannounced and on-site residency is a hard gate until the maintainer can move to California.

Pitch angle — Proof keeps an agent’s reasons beside the code as typed Markdown records under `.flatbread-proof/`. An Effort holds one thread of work. Issue, Finding, Decision, Constraint, Risk, Citation, and Blob records sit under it, linked by `derives_from`, `supersedes`, `invalidates`, and `cites`. Reads return a digest capped at 25 records, one hop, 50 edges, and 64 KiB. That is a public-good memory substrate, not a hosted product. Astera funds open tools other people can build on. A residency would pay salary and a compute budget to run the five recall experiments already scoped: harder questions, growing graphs, typed edges versus prose-only graphs, token cost, and the 4/4 write gate. The deliverable is a public eval suite, open graphs, and a write-up of what structure changes a later agent’s behaviour.
