The 120 Hz performance mode on Meridian needs a cheaper preset than Performance, so Tern ships four presets: Quality, Balanced, Performance and Ultra Performance. Ultra Performance is offered only in the 120 Hz mode, not as a general menu option, which keeps saltglass tuning to the one mode that needs it.
