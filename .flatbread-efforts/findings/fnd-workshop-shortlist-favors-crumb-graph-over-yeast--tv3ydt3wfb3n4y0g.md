Naming workshop for longform agent memory (today: Effort Graph) against Flatbread brand fit.

- Yeast metaphors (Leaven, Sourdough, Starter) clash with Flatbread as unleavened bread.
- Proof is already taken as the DAG execution surface; the memory product needs a peer-level name, not another subsystem label alone.
- Crumb Graph landed as cute, brandable, and honest: agents leave reasoning crumbs in-repo; recall follows the trail; Graph keeps the relational structure visible.
- Effort Graph remains useful as a technical/descriptor name for the same system (primitives anchored by Effort, graph of reasoning records).

Kind: qualitative brand workshop, not a measurement.
